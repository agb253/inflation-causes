Every cause, every quarter: values, data and equations

Units: percentage points of year-over-year PCE inflation (each quarter = the four quarters ending then; equation E2). Rows are causes; the last columns give the 2021-24 total (the four Q4-over-Q4 rates added up), its 68% and 90% ranges from 1,000 redraws, the data series used and the equations (numbered below). Every line except the groups adds up, with pre-existing and "other & not explained", to actual inflation in every quarter.

  • Same numbers, one row per cause and quarter, with 68% and 90% ranges for each quarter: output/reproduce_long.csv.
  • Rebuild: bash run_report.sh (all numbers); this table alone: python src/make_reproduce_table.py.
  • Data files, links, download dates: output/TABLE_UNIFIED.md, section "Data sources".

Equations

#EquationCode
E1Contribution of cause k: c_k,t = pi_t(all inputs) - pi_t(input k removed). pi is simulated with E10-E12 from 2020Q1 on; quarters before 2020 are actual history.src/unified_model.py (unified_model.causes_inflation)
E2Year-over-year number in the table: average of the last 4 quarterly (annualized) c_k, times r_t = percent change / log change of the PCE price index (DPCERG), so all lines sum to official inflation.src/unified_model.py (unified_model.yoy, save)
E3Relief to GDP: G_t = 100/PotGDP_t x sum_p m_p x sum_h (1-lambda) lambda^h X_p,t-h; lambda = 0.74; m_p from CBO 56537 Table 3 (0.36 PPP, 0.67 unemployment, 0.60 rebates, 0.88 state & local, 0.78 other, 0.37 revenue). Payments before March 2021 = Trump; from March 2021 = Biden.src/fiscal_by_law.py (fiscal_by_law.run_variant)
E4GDP to unemployment (Okun): du_t = beta x G_t, beta = -0.815 (s.e. 0.037), estimated 1990-2019.src/unified_model.py (unified_model.okun)
E5Pent-up demand: forced saving = sum over 2020-21 of (2015-19 log-linear trend - actual) real PCE = $786 billion (2017 $); spent evenly 2021Q2-2023Q3; G_t = 0.78 x spending_t / PotGDP_t; then E4.src/pentup.py (pentup.effect)
E6Fed to unemployment: monthly proxy SVAR (12 lags, 1977-2019), instrument MPS (F = 9.5); counterfactual policy shocks hold the proxy funds rate at its 2019Q4 level (2.35%) in each episode window.src/fed_svar.py (fed_svar.py, unified_model.fed_effect)
E7COVID shutdown to unemployment: du_t = g0 s_t + g1 s_t-1, g0 = 15.25 (2.33), g1 = -4.28 (2.36), OLS 2020Q1-2022Q4, no constant; s = Oxford stringency / 100, faded to 0 by 2023Q2.src/unified_model.py (unified_model.covid_fit)
E8Unemployment to V/U: log(V/U)_t = a + b u_t, b = -0.290 (1990-2019). Cause k's V/U change = L_t x b x du_k,t with L_t = (V/U_t - V/U_ref) / (log V/U_t - log V/U_ref), so the parts add up exactly.src/unified_model.py (unified_model.run_once)
E9Worker shortage: e_t - e_2019Q4, where e_t = log(V/U)_t - a - b u_t (the V/U that unemployment doesn't explain); weighted as in E8.src/unified_model.py (unified_model.run_once)
E10Wage growth (Bernanke-Blanchard): gw_t = c + 4 lags gw + 4 lags V/U + 4 lags 1-yr expectations + 4 lags catch-up + productivity; own + expectation lags sum to 1; 1990-2019.src/bb_model.py (bb_model.estimate)
E11Price inflation: gp_t = c + 4 lags gp + gw (0-4 lags) + energy/ECI, food/ECI, GSCPI, greed (0-4 lags each) + productivity; own lags + wage terms sum to 1; 1990-2024.src/bb_model.py (bb_model.estimate, unified_model.estimate_with_greed)
E12Expectations: 10-yr on gp (0-4) + own lags; 1-yr on own lags + 10-yr (0-4) + gp (0-4); each sums to 1.src/bb_model.py (bb_model.estimate)
E13Greed: residual of margin_t = -400 dlog(1 - unit profits / price) regressed on GSCPI, V/U, energy, food, wages (0-4 lags each), 1990-2024 (R^2 0.51).src/unified_model.py (unified_model.add_greed)
E14Pre-existing: pi_t with every input at its 2019 reference (no relief, no Fed moves after 2019, energy and food relative prices flat, GSCPI and productivity at 1998/1990-2019 means), plus pre-2020 Fed surprises.src/unified_model.py (unified_model.causes_inflation)
E15Not explained: actual - model (E10-E12 with every actual input), plus productivity and energy & food shocks after 2023Q1.src/unified_model.py (unified_model.causes_inflation)

To reproduce one cell: run src/unified_model.py (it prints every estimated constant to output/unified_model_run.log), then for cause k compute E1 for each quarter, average the last four quarters, and multiply by r_t (E2). The point values above are output/unified_causes_quarterly.csv, column k.
